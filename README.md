# أداة تنزيل فيديوهات يوتيوب

أداة سطر أوامر عربية بسيطة لتنزيل فيديوهات يوتيوب أو استخراج الصوت بصيغة MP3 باستخدام مكتبة [`yt-dlp`](https://github.com/yt-dlp/yt-dlp).

## المتطلبات

- Python 3.8 أو أحدث
- `ffmpeg` لدمج الفيديو والصوت أو استخراج MP3

### تثبيت FFmpeg

على Ubuntu/Debian:

```bash
sudo apt update && sudo apt install ffmpeg
```

على Windows أو macOS، راجع [دليل FFmpeg الرسمي](https://ffmpeg.org/download.html).

## التشغيل

```bash
python youtube_downloader.py
```

سيتم تثبيت `yt-dlp` تلقائيًا عند أول تشغيل إذا لم تكن مثبتة. ويمكن تثبيتها يدويًا:

```bash
python -m pip install yt-dlp
```

تُحفظ الملفات داخل مجلد `downloads`.

## الخيارات

1. تنزيل فيديو بأعلى جودة متاحة.
2. تنزيل الصوت فقط بصيغة MP3 بجودة 192 kbps.
3. تنزيل قائمة تشغيل كاملة بصيغة فيديو.
4. اختيار حد أقصى لجودة الفيديو، مثل 1080 أو 720.

## ملاحظات قانونية

استخدم الأداة فقط لتنزيل المحتوى الذي تملك الحق في تنزيله أو الذي يسمح صاحبه بذلك، والتزم بشروط خدمة YouTube والقوانين المحلية. هذه الأداة ليست تابعة لـ YouTube.
